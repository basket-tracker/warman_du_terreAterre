# 237Match

**237Match** is a relationship matching application designed for Cameroonians in Cameroon and in the diaspora.  
The goal is to help people find serious, trusted, and culturally relevant connections through verified profiles, smart matching, and secure communication.

The mobile app is built with **Flutter**, while the backend is powered by **Rust** for performance, safety, and scalability.

## Features

- User registration and login
- Profile creation and editing
- Photo upload
- Location-based matching
- Relationship preference filters
- Like, pass, and match system
- Real-time chat after matching
- English and French support
- Report and block users
- Secure backend API
- Future Mobile Money payment support

## Tech Stack

### Mobile App
- Flutter
- Dart
- Riverpod / Bloc for state management
- Dio or HTTP for API requests

### Backend
- Rust
- Axum or Actix Web
- PostgreSQL
- SQLx or Diesel
- JWT authentication
- WebSocket support for chat
- Docker for deployment
